# 🎮 Shape Game

A simple and interactive **Shape Game** created using **HTML and CSS**.  
This project demonstrates basic front-end concepts like shapes, hover effects, and CSS transformations.  
Perfect for beginners learning web development.

---

## 🚀 Features

- 🟥 **Square** with hover color effect  
- 🔵 **Diamond** shape using CSS rotation  
- 🟢 **Circle** created using `border-radius`  
- ✨ Smooth hover interactions  
- 📱 Responsive layout using Flexbox  

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**

## 🎯 How It Works

- The shapes are created using `<div>` elements
- CSS Flexbox is used to center the shapes
- Hover effects change background colors
- The diamond is rotated using `transform: rotate(45deg)`

---

## 🧠 Learning Outcomes

- Understanding CSS Flexbox
- Creating shapes with CSS
- Using hover effects
- Applying transformations (rotate)
- Structuring a basic front-end project
