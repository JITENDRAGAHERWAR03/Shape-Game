# 🎮 Shape Game

A simple and interactive **Shape Game** created using **HTML and CSS**.  
This project demonstrates basic front-end concepts like shapes, hover effects, and CSS transformations.  
Perfect for beginners learning web development.

---

## 🚀 Features

- 🟥 **Square** with hover color effect  
- 🔵 **Diamond** shape using CSS rotation  
- 🟢 **Circle** created using `border-radius`  
- ✨ Smooth hover interactions  
- 📱 Responsive layout using Flexbox  

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
